<aside>
🧣

KANGA is the design system for SecureVoice Shield: the public app, WhatsApp bot, USSD and SMS, the Live Call Guardian and the business console. It is named after the East African printed cloth. A kanga has three parts, and every Shield screen has the same three: the **pindo** (border) frames and protects, the **mji** (body) holds the content, and the **jina** (the one-line message printed on every kanga) carries one short, plain sentence.

</aside>

## 1. Principles

1. **Calm over alarm.** Scammers use fear. Shield is the slow, steady voice. No sirens, no flashing red, no countdown timers on public surfaces.
2. **One message per screen.** Every result has a single jina line, such as "Stop. Do not send money." Details sit underneath.
3. **Honest uncertainty.** Shield never says "safe" or "real" from detection alone. The best public verdict is "No warning signs found". Missing evidence always shows as "We can't tell", never as a good result.
4. **Never colour alone.** Every verdict is shape + colour + word, plus a haptic pattern on phones. It works for colour-blind users, on monochrome feature phones and in bright sun.
5. **Cheapest phone first.** Design for a 2 GB Android Go phone on 2G in Kampala, then scale up. USSD and SMS are first-class surfaces, not fallbacks.
6. **Language is the interface.** Copy is written natively in each language, not translated word for word, and reviewed by native speakers before release.
7. **Private by default.** A result during a live call is shown only to the user. It is never spoken to the caller.
8. **Same truth everywhere.** App, WhatsApp, USSD, SMS and console render the same `verdict` object. Only the rendering changes.
9. **Errors are instructions.** Every error says what to do next and includes the safe default: "Hang up and call your bank on the number on your card."

### 2.1 Personal trust mark

At onboarding each user picks one of **24 pictograms** (mango, drum, boat, star, etc.) in one of **6 colours**: 144 combinations. The pair appears on every genuine in-app result, so a fake "Shield" screenshot sent by a scammer is easy to spot.

- Never shown in WhatsApp, SMS or USSD. Those messages can be forwarded, faked as images or screenshotted.
- Never spoken by any agent.
- Changing it requires re-authentication on the device.

## 4. Typography

**Noto superfamily**, chosen for script coverage and consistent metrics:

| Script / use | Family | Notes |
| --- | --- | --- |
| Latin (EN, Kiswahili, Luganda) | Noto Sans | Covers Luganda ŋ / Ŋ. Display cuts for headings. |
| Arabic | Noto Sans Arabic | RTL, line-height 1.6 |
| Urdu | Noto Nastaliq Urdu | Line-height at least 2.0. Nastaliq needs vertical room. |
| Hindi | Noto Sans Devanagari | Line-height 1.6 |
| Codes, IDs, amounts in the console | Noto Sans Mono | Tabular figures |

Fonts are subset per locale, shipped as WOFF2 with `font-display: swap`. Public surfaces load two weights only (400, 600) to save data.

| Style | Public app (size / line) | Console (size / line) |
| --- | --- | --- |
| Display | 32 / 40 | 28 / 36 |
| H1 (jina line) | 26 / 34 | 22 / 30 |
| H2 | 22 / 30 | 18 / 26 |
| Body | **19 / 28** | 14 / 20 |
| Body small | 16 / 24 | 13 / 18 |
| Caption | 14 / 20, never for critical information | 12 / 16 |
| Mono | 15 / 22 | 13 / 18 |
- Public body text is 19px because many users are older or reading in direct sunlight.
- Phone numbers, amounts and codes always use Latin digits so they can be copied into a dialer. Prose may follow locale digits.
- Verdict lines never truncate. They wrap.
- Line length 40–60 characters on public screens.

## 5. Layout and spacing

- 4-point base grid. Spacing tokens `kg.space.*`: 0, 2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64.
- Touch targets at least **48 × 48 dp** with 8 dp between targets. That is double WCAG 2.5.8's 24px minimum.
- Primary action sits in the bottom thumb zone. One primary action per screen.
- Radii: 6 inputs, 12 cards, 20 sheets, full for pills.
- Pindo border: 2px verdict-coloured border plus an optional 6px woven pattern band on result cards.
- Elevation: 0 flat, 1 cards (`0 1px 2px rgba(17,24,39,.06)`), 2 sheets, 3 modals.
- Breakpoints: compact up to 599, medium 600–1023, expanded 1024+, console wide 1440+.
- Layout uses logical properties (`margin-inline-start`), so Arabic and Urdu mirror automatically.

## 7. 3D: the Shield Orb

A soft, glass-like shield shape that means "Shield is with you". Used only on the Guardian screen, onboarding and the marketing hero.

| Item | Spec |
| --- | --- |
| Geometry | 8,000 triangles or fewer, one mesh, baked ambient occlusion, one key light |
| Assets | glTF binary 400 KB or smaller (meshopt), KTX2 / Basis textures at 1024² or smaller |
| Web | React Three Fiber, lazy-loaded after first paint, paused when off-screen |
| Mobile | Rive 2D rendition. No real-time 3D on Android Go. |
| Tier A (flagship) | Real-time 3D at 60 fps |
| Tier B (mid-range) | Rive or pre-rendered loop at 30 fps |
| Tier C (Android Go, battery saver, data saver, reduced motion) | Static SVG |

| Orb state | Behaviour |
| --- | --- |
| Idle | Slow 4 s breathing |
| Listening | Ripple bound to the live input level |
| Analysing | Pindo pattern threads orbit the edge |
| Result | Settles and takes the verdict tint and glyph |
| Offline | Desaturated, dashed outline |

The orb never acts out a verdict before the server responds.

## 8. Illustration

Flat, warm line illustration with people from all four markets: a boda-boda rider, a market trader, an office worker in Dubai, grandparents, a student; kanzu, kitenge, abaya and hijab. Scams are drawn as a phone or a situation, never as a hooded or dark-skinned "villain". Text never appears inside images, so every illustration works in every language.

## 9. Loaders and progress

| Pattern | When | Spec |
| --- | --- | --- |
| Skeleton | Lists and dashboards | `kg.gradient.skeleton`. Never used for verdicts. |
| Pindo weave | Short analysis, under 4 s | Border threads weave around the card, 1.2 s loop |
| Live waveform | Recording or listening | Bound to mic level. Static bars under reduced motion. |
| Analysis stepper | Voice-note and number checks | Received → Checking the voice → Checking the number → Checking the story → Result. A step ticks only when the server sends that SSE event. No fake progress. |
| WhatsApp interim | Verdict not ready after 12 s | "Still checking. This can take up to a minute. While you wait, don't send money or share any code." |
| USSD | Every screen | Reply within 2 s. If a check is slower: "We will SMS your result in under 1 minute." Then end the session. |

Timing rules:

- No loader for anything under 150 ms.
- Once shown, a loader stays at least 400 ms so it never flickers.
- After 4 s, add a plain explanation line.
- After 12 s, offer "Keep checking in the background".
- Hard timeouts per surface live in **02 — Platform & API Behaviour**.

## 10. Shells and navigation

### 10.1 Mobile app (Expo React Native)

- **Bottom tab bar, 5 tabs:** Check · Guardian · Family · Report · Learn. Labels always visible. Active tab gets a lake.700 icon, label and a 3px top indicator.
- **Top app bar:** back, title, and the personal trust mark on the right. Settings opens from the avatar. No hamburger menu.
- **Home (Check)** opens with one large input: "Paste or type a number". Below it: "Check a voice note" and "Was that call real?".

### 10.2 WhatsApp bot

- Verified business profile. Welcome message plus a **list message** (up to 10 rows, row titles up to 24 characters) and **reply buttons** (up to 3, titles up to 20 characters).
- Reply buttons: Check a number · Check a voice note · Report a scam.
- List rows: Check a number · Check a voice note · Was this call real? · Report a scam · Protect my family · Safety tips · Language · Delete my data · Talk to a person.
- Verdict messages open with shape emoji plus word, then reasons, then steps:

```
🛑 STOP. This looks like a scam.

Why:
• This number was reported 14 times this week for "money sent by mistake" requests.
• The voice in your clip may be computer-made.

What to do now:
1. Do not send money or share any code.
2. Hang up.
3. Call your bank on the number on your card.

Shield never calls you first.
Check ID …7Q2K
```

Emoji mapping: Danger 🛑, Caution ⚠️, Inconclusive ❔, Clear 🟢, Verified call 🛡️. The emoji is always followed by the word.

### 10.3 USSD (feature phones)

- Menus stay at **160 characters or fewer** (GSM-7). The spec maximum is 182, but some operators cut earlier. At most 7 options, numeric only. `0` Back · `00` Main menu · `98` More.
- Short code per market is to be assigned.

```
Shield
1 Check a number
2 Was that call real?
3 Report a scam
4 Protect my family
5 Safety tips
6 Language
```

```
Ngao
1 Kagua namba
2 Simu ile ilikuwa halali?
3 Ripoti utapeli
4 Linda familia yangu
5 Vidokezo vya usalama
6 Lugha
```

Luganda menus are authored by a native writer. Development builds show bracketed English placeholders, and release is blocked until review is complete.

### 10.4 SMS

- GSM-7 allows 160 characters per segment. UCS-2 (Arabic, Urdu, Hindi) allows only 70, so those templates are written ultra-short.
- Luganda **ŋ** is not in GSM-7. SMS uses the accepted **ng'** spelling, which keeps messages in GSM-7.
- Registered alphanumeric sender ID per market where allowed.
- **No links in SMS. Ever.** Teaching users to tap links in SMS is what phishing relies on.

### 10.5 Business console (Next.js)

- **Left rail:** 72px collapsed, 240px expanded. Eleven items: Overview · Live · Cases · Holds · Verified calls · Numbers · Scam waves · Policies · Evidence & audit · Integrations · Settings.
- **Top bar:** organisation switcher · **region badge (AE · KE · UG · TZ), always visible** · environment badge (Sandbox has a striped kanga.400 band; Production has none) · ⌘K search · system mode pill from `GET /v1/system/mode` · user menu.
- A full-width mode banner appears whenever the system mode is not NORMAL.
- URLs are shareable and region-scoped: `/{org}/{region}/cases/{caseId}`, `/{org}/{region}/holds?status=pending`, `/{org}/{region}/policies/{policyId}/backtests/{runId}`.
- Shortcuts: `⌘K` command palette · `g c` Cases · `g h` Holds · `j` / `k` next and previous · `?` help. Release and approve have no single-key shortcut. They always open a confirmation.
- Density: comfortable (default) or compact.

### 10.6 Marketing site navbar

Logo · Product (Public app, Guardian, Business API) · For banks · For telcos · Trust & privacy · Pricing · Docs · language switcher · primary button **Check a number**. Sticky, 64px tall, hides on scroll down and returns on scroll up. On mobile it becomes a full-screen sheet.

## 12. Key screens

**Verdict card anatomy, top to bottom:**

1. Pindo border in the verdict colour (2px plus pattern band).
2. Verdict glyph (48dp).
3. Jina line in H1: one sentence.
4. "What to do now": at most 3 numbered steps.
5. "Why we think this": plain-language reasons, such as "The SIM card for this number was changed 2 hours ago."
6. "Get help": the official contact from the registry, such as "Call your bank on the number on your card."
7. Footer: trust mark, time of check, short check ID in mono (last 6 characters) for support.

**Public screens:** Check (home) · Number result · Voice-note result · Guardian (brief, in-call, result) · Verified call · Report · Family · Learn lesson · Settings & privacy (including "Delete my data") · Appeal (for a number owner who thinks they were wrongly flagged).

**Console screens:** Overview · Live feed · Case detail (timeline, signals, evidence, actions) · Hold queue · Policy editor and backtest report · Scam-wave cluster · Audit explorer (with chain-verified tick) · Integrations (keys, webhooks, delivery log) · System mode and status.

## 14. Modals and confirmations

- **Public:** avoid modals and use full-screen steps. Modals appear only for destructive actions ("Delete my data") and for leaving the Guardian mid-call.
- **Console release-hold dialog** shows the amount (formatted from minor units), payee, triggering signals and policy version. It requires a reason code plus a note of at least 20 characters, and typing `RELEASE` to confirm. It records the first approver and waits for a **different** second approver (four-eyes).
- Focus is trapped inside the dialog. Initial focus goes to the least destructive action. Esc closes non-destructive dialogs only.

| Degraded mode | Banner: "Some checks are slower right now. You may see 'We can't tell' more often." | Mode banner with the affected signals |
| Permission denied | "This needs your permission" plus a plain reason | Role and the required permission |
| Fatal error | Inconclusive card with the safe default | Error page with incident ID and retry |

## 16. Error and loading boundaries

- **Boundary tree:** app root → tab → screen → widget. Each level has its own fallback, so one broken widget never blanks a screen.
- **The verdict boundary fails safe.** If the verdict component crashes or receives an invalid payload, it renders the **Inconclusive** card with the safe default. It never renders blank or green.
- **Console:** route-level boundaries with retry and incident ID. Data grids keep the last good data under a stale banner.
- **Suspense:** loading boundaries wrap each data region, never the whole page, and follow the timing rules in section 9.

### 16.1 Error envelope

All surfaces consume the same RFC 9457 problem document defined in **02 — Platform & API Behaviour**: `type`, `title`, `status`, `code` (`SH-…`), `detail`, `instance`, `traceId`, `retryable`, `retryAfterMs`, `safeAction`. The UI maps `code` to localised copy. Public surfaces never show `detail` verbatim.

| Code | Public copy (EN) | Console copy |
| --- | --- | --- |
| `SH-AUDIO-415` | "We can't open this file. Try forwarding the voice note again." | Unsupported media type |
| `SH-AUDIO-422` | "This clip is too short. We need at least 3 seconds of the caller's voice." | Audio below minimum speech duration |
| `SH-RATE-429` | "You've checked a lot today. Try again in 10 minutes." | Rate limit, retry after N seconds |
| `SH-DETECT-503` | "We couldn't finish the voice check. Treat this call with care: hang up and call back on an official number." | Detector unavailable, verdict floored to Inconclusive |
| `SH-TELCO-504` | "We couldn't check the SIM card right now." | Telco timeout, SIM signal `unknown` |
| `SH-CONSENT-451` | "Shield can't check this call because the other person has not been told Shield is listening." | Blocked by consent or legal rule |
| `SH-REGION-421` | Not shown | Request reached the wrong region cell |
| `SH-AUTH-401` | "Please sign in again." | Session expired |
| `SH-INTERNAL-500` | "Something went wrong on our side. Hang up and call your bank on the number on your card." | Internal error with incident ID |

## 17. Motion

Motion explains what changed. It never entertains on a result screen, and never bounces or shakes on Danger.

| Token | Value | Use |
| --- | --- | --- |
| `kg.motion.instant` | 0 ms | Reduced motion |
| `kg.motion.fast` | 120 ms, ease-out | Press, toggle, checkbox |
| `kg.motion.base` | 200 ms, cubic-bezier(0.2, 0, 0, 1) | Most transitions |
| `kg.motion.slow` | 320 ms | Sheets, screen transitions |
| `kg.motion.reveal` | 900 ms total | Verdict reveal. A deliberate pause: "slow down" in motion. |
| `kg.motion.spring.calm` | stiffness 170, damping 26, mass 1 (no overshoot) | Orb, cards |
| `kg.motion.breath` | 4,000 ms loop | Orb idle |

**Micro-interactions:** button press scales to 0.98 · toggle slide 120 ms · copy-to-clipboard tick · number formatting as you type · stepper tick with a selection haptic · pull-to-refresh weaves the pindo.

**Macro choreography:**

- Verdict reveal: border draws (300 ms) → glyph fades in (200 ms) → jina line (200 ms) → actions (200 ms).
- Guardian join and leave: the orb rises in and settles out.
- Tab change: 200 ms cross-fade. No slides on Android Go.
- Console: route changes are instant. Side panels slide in over 200 ms.

**Safety:** nothing flashes more than 3 times per second (WCAG 2.3.1). Under reduced motion, everything becomes a cross-fade of 120 ms or less and the orb is static.

## 18. Haptics

The pulse count is a language: **1 pulse = no warning signs · 2 = be careful or can't tell · 3 = stop.** Onboarding teaches it: "Feel three buzzes? Stop." This lets a user get the Guardian result without looking at the screen, which also helps blind users.

| Event | iOS | Android | Web |
| --- | --- | --- | --- |
| Press | `UIImpactFeedbackGenerator` light | `KEYBOARD_TAP` / `VIRTUAL_KEY` | None |
| Step complete | `UISelectionFeedbackGenerator` | `CLOCK_TICK` (`SEGMENT_TICK` on API 34+) | None |
| Clear (1) | `UINotificationFeedbackGenerator` success | `CONFIRM` (API 30+) | `vibrate(60)` where supported |
| Caution or Inconclusive (2) | Notification warning | `EFFECT_DOUBLE_CLICK` | `vibrate([60,120,60])` |
| Danger (3) | Notification error + Core Haptics pattern of 3 long pulses | `REJECT` (API 30+), else waveform `[0,300,150,300,150,300]` | `vibrate([300,150,300,150,300])` |
| Verified call | Success + light impact | `CONFIRM` | `vibrate(60)` |
- Implementation: `expo-haptics` (impact, notification, selection, Android haptic types), Core Haptics and `VibrationEffect.Composition` behind a capability check.
- The Web Vibration API does not work in iOS Safari. There, the visual and audio cue carries the result.
- **During calls**, iOS may limit vibration for a backgrounded app. The Guardian result also arrives as a time-sensitive notification and as a WhatsApp or SMS message.
- Settings: haptics on or off and intensity. System touch-feedback settings are respected.

## 19. Sound

- Earcons are short and soft: "listening started" (two rising notes) and "result ready" (one neutral note).
- **The result-ready tone is the same for every verdict.** If the caller overhears it, they learn nothing. The verdict travels by haptics and on screen.
- No sound plays on speakerphone during a Guardian call.

## 20. Content design

Write for a reading age of about 11–12 in every language. Short sentences, active voice, no blame.

| Use | Avoid |
| --- | --- |
| "No warning signs found" | "Safe", "Real", "Verified" (unless the registry says so) |
| "This looks like a scam" | "Fraudster detected" |
| "Hang up and call your bank on the number on your card" | "Contact customer care". Scammers pretend to be customer care. |
| "We can't tell" | "Error", "Unknown", "Null" |
| "The SIM card for this number was changed recently" | "SIM swap event detected (CAMARA)" |
| "A computer may have made this voice" | "Deepfake", "synthetic speech" on public surfaces |
| "Shield never calls you first" | Anything that implies Shield might call |
| "Lots of people lose money this way" | "You should have known" |

### 20.2 Formats

- **Money:** AED 1,234.50 (2 decimals) · KES 1,234.50 (2 decimals) · UGX 1,234 (0 decimals) · TZS 1,234 (whole shillings; cents shown only if non-zero). Values come from integer minor units and the ISO 4217 exponent. Never round in the UI.
- **Phone numbers:** +971 50 123 4567 · +254 712 345 678 · +256 772 123 456 · +255 754 123 456. Notifications mask all but the last 3 digits.
- **Dates:** "21 Oct 2025", never 10/11/12-style numerics.
- **Times:** 24-hour digits in the viewer's zone (09, rule T-3). When that differs from the user's own zone, name it: "14:05 Dubai time (13:05 in Dar es Salaam)". Relative times such as "2 hours ago" come from the server (09, rule T-7).
- **Time in Kiswahili and Luganda:** speech uses East African time, which counts hours from 6 a.m. "Saa mbili usiku" is 8 p.m. Screens show 24-hour digits (20:00) with the spoken form beside them, and agents say the local form. Native review confirms each string.

## 21. Accessibility

- WCAG 2.2 AA minimum on every surface, verified per release.
- VoiceOver and TalkBack labels on every control. A Danger verdict is announced through an assertive live region, other verdicts politely.
- Dynamic type to 200% with no truncation of verdicts or actions.
- No time limits on public flows, except the operator-imposed USSD session.
- Low literacy: icons with every label, audio explanations in Learn, and a pictogram trust mark.
- Results are read aloud on request, but **never during a call**, so the caller cannot hear them.
- Colour-blind safe by design (shapes and words), checked with deuteranopia, protanopia and tritanopia simulation in CI.

## 22. Internationalisation

- **Locales:** en-AE, ar-AE, hi-AE, ur-AE, en-KE, sw-KE, en-UG, sw-UG, lg-UG, en-TZ, sw-TZ.
- **Messages:** ICU MessageFormat. Arabic has six plural categories. Luganda noun classes change agreement, so strings are never concatenated from fragments.
- **Fallback chains:** lg-UG → en-UG · sw-UG → sw-KE → en-UG · sw-TZ → sw-KE → en-TZ · ur-AE → en-AE · hi-AE → en-AE · ar-AE → en-AE. Safety strings never fall back silently. A missing safety string fails the build.
- **Layout:** logical CSS properties and RN `I18nManager` for RTL. Budget 40% text expansion. Pseudo-localisation (accented and RTL) runs in CI.
- **No text in images.** Fonts are subset per locale.

## 23. Tokens

Tokens are W3C Design Tokens (DTCG) JSON in `packages/tokens`, built with Style Dictionary into CSS variables (site and console) and TypeScript constants (React Native).

```json
{
  "kg": {
    "color": {
      "paper": { "$type": "color", "$value": "#F8F6F1" },
      "ink": { "900": { "$type": "color", "$value": "#111827" } },
      "verdict": {
        "danger": {
          "fg": { "$type": "color", "$value": "#B4231A" },
          "bg": { "$type": "color", "$value": "#FDE7E5" },
          "dark": { "$type": "color", "$value": "#FF8A80" }
        }
      }
    },
    "motion": {
      "reveal": { "$type": "duration", "$value": "900ms" },
      "base": { "$type": "duration", "$value": "200ms" }
    },
    "haptic": {
      "danger": { "$type": "string", "$value": "pulse-3" }
    }
  }
}
```

```css
:root {
  --kg-color-paper: #F8F6F1;
  --kg-color-ink-900: #111827;
  --kg-color-verdict-danger-fg: #B4231A;
  --kg-color-verdict-danger-bg: #FDE7E5;

}
```

**Lint rules:** no raw hex outside `packages/tokens` (Stylelint and ESLint) · `kg/no-verdict-color-outside-verdict` · a contrast test across all token pairs · a missing-translation check for safety strings.

## 26. Governance and design process

1. **Propose:** an RFC in `docs/design/rfcs` with the problem, options and a11y impact.
2. **Design:** Figma library kept in sync with tokens (Tokens Studio), using real copy in all launch languages.
3. **Review:** design lead, accessibility check, native-language review for any copy change.
4. **Build:** Storybook stories for every state in section 15, with Playwright visual regression in light, dark, RTL and 200% text.
5. **Release:** semver (`kanga@1.0.0`) with changelog. Breaking token changes need a migration note.
6. **Audit:** accessibility and low-end performance audit every release, plus a quarterly usability test in each market.
